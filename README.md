# OSRS Shop Hop Sell Calculator

OSRSSHSC helps maximize your profit from selling bulk items in Old School RuneScape shops.

And shows which shops pay the most for your items.

Go to: https://f0nkey.github.io/osrs-sell-sim/

![img.png](img.png)

## Synopsis

Stores in Old School RuneScape pay less for each additional copy of an item you sell them.

If you sell 3 magic logs, without hopping worlds, the buy price will drop by 3% for each additional log sold.
1. Sell 1st log, get 128 gp
2. Sell 2nd log, get 118 gp
3. Sell 3rd log, get 108 gp

**Total Profit: 354 gp**

But if you hop to a new world each sell, the price resets to the base value.
1. Sell 1st log, get 128 gp
2. Hop to a new world
3. Sell 2nd log, get 128 gp
4. Hop to a new world
5. Sell 3rd log, get 128 gp

**Total Profit: 384 gp**

This calculator estimates profit based on the number of hops and amount of items sold each hop.

And scans shop data from the wiki's [storeline bucket](https://oldschool.runescape.wiki/w/Bucket:Storeline), detecting special pricing from specialty shops.

## Disclaimer

You should sell to the [Grand Exchange](https://oldschool.runescape.wiki/w/Grand_Exchange) in most cases instead of a shop.
This tool is targeted to Ironman players who cannot access it.
