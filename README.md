# OSRS Shop Hop Sell Calculator

Go to:
https://f0nkey.github.io/osrs-sell-sim/

General stores in Old School RuneScape pay less for each additional copy of an item you sell them.

The price drops by a fixed percentage of the item’s base value with each sale (typically 3% for standard stores).

For magic logs, as an example:
- 1st sale: 128 gp
- 2nd sale: 118 gp
- 3rd sale: 108 gp
- … continuing down to a minimum of 32 gp

Hopping to a new world with fresh stock resets the price. This calculator estimates profit based on the number of hops.
